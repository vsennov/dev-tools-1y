# Лабораторная работа №4. Знакомство с Linux

## Цель работы

Познакомить студента с базовой работой со средой Linux (установкой, настройкой,
использованием) и простыми средствами виртуализации.

## Процесс работы

По ходу выполнения работы фиксируйте промежуточные шаги для каждого этапа.
Приведите скриншоты процессов установки и настройки операционной системы.

Работу с операционной системой предполагается производить на виртуальной машине.
Доступными вариантами являются:

- [VirtualBox](https://www.virtualbox.org/),
- [VMware Workstation / Fusion](https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion),
- [QEMU](https://www.qemu.org/).

Самым простым является первый вариант с VirtualBox.

### Выбор варианта

В рамках работы необходимо установить дистрибутив Linux и оконный менеджер, они
выбираются в соответствии с вариантом, указанным в таблице.

Вариант выбирается по первому символу MD5-хеша вашего ФИО. Например:

```console
[vova@archvova dev_tools_1y]$ echo "Сеннов Владимир Николаевич" | md5sum 
3b07d4d531a1ec468b55b0de9b25c1e7  -
```

Тут первый символ `3`, и я могу выбрать из таблицы один из вариантов из строки
таблицы, где указан код `3`. Можно выбрать либо сложный вариант, либо простой
вариант.


| Код | Простой вариант         | Сложный вариант        |
| --- | ----------------------- | ---------------------- |
| 0   | Linux Mint + Cinnamon   | Arch + GNOME/KDE       |
| 1   | Linux Mint + Xfce       | Arch + Sway/Hyprland   |
| 2   | Ubuntu + GNOME          | Arch + Xfce/LXQt       |
| 3   | Ubuntu + Xfce (Xubuntu) | Gentoo + GNOME/KDE     |
| 4   | Ubuntu + KDE (Kubuntu)  | Gentoo + Sway/Hyprland |
| 5   | Ubuntu + LXQt (Lubuntu) | Gentoo + Xfce/LXQt     |
| 6   | Debian + GNOME          | Void + GNOME/KDE       |
| 7   | Debian + KDE            | Void + Sway/Hyprland   |
| 8   | Debian + Xfce           | Void + Xfce/LXQt       |
| 9   | Manjaro + GNOME         | openSUSE + GNOME/KDE   |
| A   | Manjaro + Xfce          | openSUSE + Xfce        |
| B   | Manjaro + KDE           | Alpine + любой DE      |
| C   | Pop!_OS + COSMIC        | NixOS + GNOME/KDE      |
| D   | KDE Neon                | NixOS + Sway/Hyprland  |
| E   | Zorin OS                | CRUX                   | 
| F   | Fedora + GNOME          | Slackware              |

Зафиксируйте в отчете ваш вариант и способ, которым вы получили его код.

### Изучение особенностей дистрибутива

1. *Узнайте* следующие детали про ваш дистрибутив по варианту:

  - какая организация занимается разработкой и поддержкой вашего дистрибутива;
  - если дистрибутив является надстройкой над другим, укажите базовый
    дистрибутив;
  - как часто выпускаются релизы у этого дистрибутива, какой релиз последний;
  - какие ресурсы доступны для изучения деталей работы с дистрибутивом (wiki,
    форумы).

2. *Узнайте*, какой пакетный менеджер использует ваш дистрибутив. Узнайте, каким
   образом можно искать, устанавливать, обновлять и удалять пакеты.

3. *Узнайте*, как происходит процесс установки вашего дистрибутива, какие
   документы или инструкции вам могут понадобиться.

4. *Узнайте* минимальные системные требования для вашего дистрибутива **и
   оконного менеджера**.

### Установка ОС

1. Создайте виртуальную машину в соответствии с минимальными требованиями для
   вашего варианта.
2. Загрузите образ для установки последнего релиза вашего дистрибутива. Если
   разработчик предоставляет такую возможность, выберите версию сразу с нужным
   оконным менеджером.
3. Проведите установку ОС на виртуальную машину согласно инструкциям от
   разработчика.
4. Убедитесь, что ОС доступна после перезагрузки виртуальной машины.

### Настройка и установка пакетов

В этом разделе необходимо установить и настроить пакеты, которые позволят решать
типовые задачи при работе с операционной системой. Не обязательно устанавливать
программу для каждого пункта, важно показать, что такая возможность в системе
есть, и указать, какими средствами это достигается. Устанавливайте новые пакеты
с помощью рекомендуемого в дистрибутиве способа.

1. Возможность открывать несколько программ (окон), переключаться между ними.
2. Отслеживание системных ресурсов (оперативной памяти, загрузки ЦПУ, количество
   места на диске), управление процессами.
3. Настройка логина/пароля пользователя; блокировка экрана.
4. Настройка сетевых подключений.
5. Работа с файловой системой (файловый менеджер или проводник).
6. Выход в интернет (браузер).
7. Инструменты для разработки (компилятор, отладчик, среда разработки).
