# Современные технологии разработки ПО

В этом репозитории располагаются материалы для практики по дисциплине
"Современные технологии разработки ПО" для студентов первого курса.

В рамках семестрового курса предполагаются следующие лабораторные работы.


| №   | Тема работы                                | Обязательная |
| --- | ------------------------------------------ | ------------ |
| 1   | Базовая работа с Git.                      | **Да**.      |
| 2   | Сдача работы в стиле GitFlow.              | **Да.**      |
| 3   | Настройка среды разработки.                | **Да.**      |
| 4   | Знакомство с ОС Linux.                     | Нет.         |
| 5   | Средства управления проектами.             | Нет.         |
| 6   | Простые CI-CD пайплайны.                   | Нет.         |
| 7   | Развертывание программы на целевой машине. | **Да.**      |


Выполнение обязательных работ **необходимо** для получения зачета (допуска).
Выполнение **всех** описанных работ позволяет получить "автомат" по всей
дисциплине.

Формулировки заданий в рамках работ помещены в директорию [tasks/](tasks/).

На данный момент для выполнения доступны:

- [Лабораторная 1](tasks/lab1.md),
- [Лабораторная 2](tasks/lab2.md),
- [Лабораторная 3](tasks/lab3.md),
- [Лабораторная 4](tasks/lab4.md).

Результатом выполнения работ студентом является отчет. Отчет должен включать:

- для каждого задания вида "узнайте" / "изучите" - краткую выжимку информации по
  теме с указанием источников;
- для каждого задания вида "сделайте" - краткое описание действий и результата.

Описание действия может быть словесным, если действие содержит текстовые
команды, приведите их в отчете. Результат можете привести скриншотом, для работы
в консоли лучше приводить текстовый вывод прямо в отчете.

> Цель вашего отчета: помочь **вам** выполнить схожую задачу через некоторое
> время.

Отчет должен быть написан в формате *Markdown* и быть приятен на глаз.

Для сдачи работ студенту нужно завести **приватный**
репозиторий на [Github](https://github.com/) и пригласить
[преподавателя](https://github.com/vsennov) в репозиторий коллаборатором. Отчеты
должны помещаться в этом репозитории.

Рекомендуемая структура файлов в репозитории выглядит следующим образом.

```
reports/
  imgs/
    ..
  lab1.md
  lab2.md
README.md
```

*Желательно* уведомлять преподавателя о готовности отчета следующим образом.

1. Изначально отчет готовится в отдельной *ветке*.
2. Когда отчет готов, создается Pull Request из этой ветки в `main`,
   преподаватель указывается в качестве Reviewer.
3. Принятый отчет отмечает пометкой `Approve` со стороны преподавателя, правки
   записываются в комментариях.

Если по какой-то причине этот вариант не получается, надо уведомить о готовности
иным способом (например, показать работу на занятии).

По итогу просмотра отчета студент может быть вызван на дополнительное интервью
для защиты работы.
